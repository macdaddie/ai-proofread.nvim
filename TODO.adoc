
= AI Proofread: Implementation TODO

== Current State

* Project name: `ai-proofread.nvim`.
* Public GitHub repository: `macdaddie/ai-proofread.nvim`.
* Public API and commands load in a clean Neovim session.
* Plain text, Markdown and AsciiDoc adapters are implemented.
* Reviews use asynchronous requests to the selected local
  backend.
* Complete buffers and visual selections can be reviewed.
* The configured Ollama model can be preloaded
  asynchronously at Neovim startup.
* Inference can use either native Apple `fm` or local Ollama.
* Validated findings are published to quickfix.
* Corrections can be applied individually or all at once.
* Recommendations can be ignored without changing the buffer.
* Headless integration tests cover the critical workflow.
* Real Ollama and native `fm` reviews produce
  source-precise quickfix entries.

== Completed

* ADR-028 restricts the response contract to spelling,
  grammar and punctuation.
* ADR-029 adds explicit individual and bulk application.
* Exact and whitespace-collapsed quotation matching.
* Ambiguous quotation rejection.
* Length-preserving markup masking and source-byte maps.
* UTF-8-safe line-local quickfix byte columns.
* Packaged JSON Schema with deterministic Ollama options.
* Sequential chunk scheduling and partial-failure handling.
* Cancellation and stale-buffer protection.
* Exact-source preflight, overlap rejection and one-step undo
  for bulk correction application.
* Successful fixes leave only outstanding recommendations in
  quickfix; failed fixes remain visible.
* Ignored recommendations are removed from quickfix and
  excluded from bulk application.
* Characterwise and linewise selection review retains
  original-buffer coordinates.
* Optional Ollama model preload respects
  `OLLAMA_KEEP_ALIVE` unless a per-request `keep_alive` value
  is configured.
* Preload has a separate timeout, classifies transport
  failures and reports them only at debug level.
* The health command lists the models currently loaded in
  Ollama.
* ADR-034 adds selectable native `fm` and Ollama backends
  behind a shared prompt and validator.
* The native `fm` adapter uses the packaged structured-output
  schema and decodes the direct JSON response.
* Suggestions identical to the quoted source text are
  rejected as no-op findings.
* `vim.pack`, lazy.nvim and native-package documentation.
* Headless Neovim test workflow.
* MIT Licence and renamed public GitHub repository.
* README, Vim help and architecture documentation updated for
  the runnable implementation and both backends.

== Deferred Format Support

=== Typst

Implement a dedicated parser or Tree-sitter-aware adapter before
enabling Typst. Regular-expression masking alone is insufficient.

=== RTF

RTF requires a parser that can produce reviewable text and a
reversible source-byte map. Raw RTF shall not be sent to the model.

== Final Phase: Language Benchmark

The benchmark begins only after the plugin passes its automated and
real-backend integration tests.

The corpus shall cover spelling, grammar, punctuation and
long-sentence rewrites, British English, protected markup,
repeated quotations and clean prose.

Include adversarial rewrite cases, abbreviation-heavy
sentences, hostile control characters and oversized model
responses.

Measure precision, recall, false-positive rate, correction accuracy,
and exact-source accuracy.
